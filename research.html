Research

My research develops machine learning that is trustworthy, data-efficient and practical to deploy, particularly when data is imbalanced, scarce or noisy. I apply it to computer vision, healthcare and assistive technology.

Full details of each paper are on the Publications page. Code for most projects is on GitHub.

Learning from imbalanced and scarce data

My M.Sc. thesis asked how the difficulty of individual training instances can guide learning when classes are imbalanced. It led to a set of methods and an experimental study of existing ones.

iCost

A cost-sensitive learning framework that weights the penalty for each training instance by how hard that instance is to learn. Released as an open-source Python package.

arXiv Code PyPI

iBRF

An improved Balanced Random Forest, an ensemble method that resamples the data for each tree to better handle class imbalance.

Paper Code

UniSyn

A unified sampling framework that addresses class imbalance and class overlap together.

Code

Evaluation of sampling techniques

Large experimental comparisons of popular and recent resampling methods across many datasets, identifying their limitations and the factors that make imbalanced learning hard.

Biomedical and accessible AI

I build diagnostic models that are explainable and usable outside well-equipped clinics, including systems that work on images captured with a phone.

Arsenicosis diagnosis from mobile-captured skin images

An end-to-end deep learning framework that uses CNNs and vision transformers, explains its predictions with LIME, and includes a web deployment for easy access.

arXiv Code

Skin lesion classification on mobile-acquired images

Multiclass classification using CNN and transformer models, with a curated dataset of more than 50 skin disease categories and Grad-CAM interpretability.

arXiv Code

Ovarian cancer decision support

An explainable machine learning system for diagnosis that uses SHAP to examine how algorithm randomness and feature selection can introduce bias, and to identify biomarkers for premenopausal and postmenopausal patients.

Paper Code

Cervical cancer, heart failure and other clinical prediction

Decision support and survival models for cervical cancer, heart failure and other conditions, including survival analysis with random survival forests.

Assistive technology: Bangla Braille

I am developing tools that make printed Bangla material accessible to blind readers. The work includes a pipeline that detects Bangla Braille in images such as book pages and translates it to Bangla text with speech output, and automated correction of recognition errors in Braille versions of primary school textbooks. I supervise undergraduate thesis work on this topic.

Explainable and fair AI

I use explainability tools, including SHAP, Grad-CAM and LIME, to check whether clinical and vision models rely on sensible evidence. I am extending this to fairness, asking whether a model's behavior and its explanations hold up across different groups of patients.

Quantum AI and machine learning

I am currently exploring how quantum computing can be applied to machine learning.

Datasets

Electricity demand and load shedding in Bangladesh

A multi-year dataset of daily electricity demand, generation, load shedding and external conditions in Bangladesh, covering November 2019 to December 2024. It was built by extracting the Bangladesh Power Development Board's daily reports. Published in Data in Brief, 2025, with Md. Ikrama Hossain, Tasnia Nafs and Sakif Yeaser.
